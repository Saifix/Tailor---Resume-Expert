# Human voice

Recruiters skim hundreds of applications that all sound the same. Generic, over-polished text gets ignored (or binned as "AI-written") long before anyone checks the facts. Write like the candidate on a good day: specific, plain, a little informal where the format allows.

**This is about honesty and specificity, not tricking anyone.** Use only facts from the candidate's resume, `resumes/facts.md`, the job post or verified research. Never use hidden text, prompt-injection tricks or keyword stuffing. (AI detectors are unreliable anyway — OpenAI withdrew its own; they flag non-native writers disproportionately. Write well; don't write *for* a detector.)

## Rules

1. **Lead with something specific** — a result, a project, a person, a product detail. Never "I am writing to…", "I hope this finds you well".
2. **Evidence over adjectives.** Every claim gets a number, name, tool or outcome from the source material. Cut adjectives that carry no evidence ("dynamic", "innovative", "passionate").
3. **Plain verbs.** use (not utilize/leverage), help (not facilitate), led/started (not spearheaded), improve (not enhance/elevate), show (not showcase/underscore).
4. **Vary sentence length on purpose.** Mix short sentences with longer ones. An occasional fragment is fine in letters and messages. Avoid a run of same-length, same-shape sentences.
5. **First person, active voice** in letters and messages ("I rebuilt…"). Resumes stay pronoun-free.
6. **Contractions** (I'm, I've, didn't) in cover letters and LinkedIn messages; none on the resume/CV.
7. **No structural tics:** no "not only X but also Y", no "it's not X, it's Y", no reflexive groups of three, no trailing "…, highlighting my commitment to…" clauses, no paragraph-ending summary/moral sentences ("This experience taught me…" only if followed by something concrete).
8. **At most one em dash per piece.** Prefer commas, colons or full stops.
9. **Hedge once, only where there is real uncertainty.** No stacked qualifiers.
10. **Low enthusiasm, high specificity.** Show interest through specifics about the employer (a product, a team, a stated challenge) — not "I'm thrilled", "dream company", flattery.
11. **Sentence-case headings, minimal bold.**
12. **Keep it short.** LinkedIn notes ≤ 300 chars; messages ≈ 60–100 words; industry cover letters one page (250–400 words). Aim for plain language around a Grade 8–10 reading level in letters and messages.
13. **Keep the candidate's own phrasing** where it exists in their resume or answers — their quirks are a feature.
14. **Read it aloud (mentally).** If a sentence sounds like a press release, rewrite it as you'd say it to a colleague.

## Phrase blocklist — avoid → use instead

| Avoid | Use instead |
|---|---|
| delve into | look at, dig into |
| tapestry, rich tapestry | mix, range — or cut |
| testament to | shows |
| pivotal, crucial, vital, plays a crucial role | key, main — or say what it changed |
| underscore, highlight (verb), showcase | show |
| leverage, utilize | use |
| facilitate | help, run |
| foster, cultivate | build, encourage |
| enhance, elevate, bolster | improve, strengthen |
| garner | get, win |
| harness, unlock, unleash | use, open up |
| spearheaded | led, started |
| streamline | simplify, speed up |
| robust | strong, reliable |
| seamless(ly) | smooth(ly) |
| meticulous(ly) | careful(ly) |
| intricate, multifaceted | complex, varied |
| innovative, cutting-edge, transformative, game-changer | name the method or the change |
| dynamic, vibrant, bustling | cut |
| landscape, realm, ever-evolving | field, area, changing |
| navigate (challenges/complexities) | handle, work through |
| embark on, journey | start, the years I spent… |
| resonates with me, aligns perfectly with | fits, matches — then say why |
| serves as, stands as | is |
| in today's fast-paced world | cut |
| it's worth noting / it is important to note | cut |
| additionally, moreover, furthermore | also, and — or start a new sentence |
| I am excited/thrilled to apply | I'm applying for [role] because [specific reason] |
| I am writing to express my interest | I'd like to be considered for [role] |
| passionate about | name what you actually did |
| unwavering commitment | give the evidence |
| proven track record, results-driven | list the results |
| ideal candidate, uniquely positioned | cut |
| a deep understanding of | experience with [named thing] |
| valuable insights | findings, lessons |
| thank you for your time and consideration | Thanks, |
| I look forward to the opportunity to… | I'd welcome a chat about… |

Tailor's automatic check flags many of these. When it does, rewrite just those parts — don't swap one stock phrase for another.
