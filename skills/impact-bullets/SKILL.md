# Impact bullets

Rewrite each kept bullet in the shape **Accomplished [X] as measured by [Y] by doing [Z]** — in practice:

> **Verb** + **what you did** (+ scope: team size, users, scale) + **result** (metric or concrete outcome).

Examples:
- Before: "Responsible for the checkout page."
  After: "Led the checkout redesign for 2M merchants, lifting conversion 4.1%." *(only if 2M and 4.1% are in the base resume)*
- Before: "Worked on performance improvements."
  After: "Cut dashboard p95 load time from 3.2s to 1.1s by moving data fetching to the server." *(numbers from the base resume)*
- No metric available: "Introduced typed API clients across 9 teams, removing a whole class of runtime bugs."

Rules:
- One line where possible, never more than two. 12–28 words.
- Strong, specific verbs: Led, Shipped, Built, Cut, Grew, Migrated, Designed, Automated, Mentored. Avoid "Helped", "Worked on", "Responsible for", "Utilized".
- **Never invent or inflate metrics.** If the base resume has no number, use a concrete outcome instead (adopted by X, replaced Y, unblocked Z).
- Put the JD-relevant noun early in the bullet so a skimming reader sees it.
- No first person, no trailing full stops inconsistency — match the base resume's punctuation style.
